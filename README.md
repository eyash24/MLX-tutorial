# MLX

## AIM
Learn MLX basics, build models and fine tune them 

## Content
The [nbs](nbs) folder contain notebooks used to study and experiment with mlx. 
-[MLX-basic](nbs/basics.ipynb): This notebook contains the mlx vector fundamentals
-[mlx-llm-fine-tuning](nbs/fine-tune.ipynb): This notebook is used for fine tuning differen Qwen/Qwen2.5-Coder models to generate a calculator script as well as retain its generalization abilities.
